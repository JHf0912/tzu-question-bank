## 二、综合题考查内容与规则

### 2.1 分治法综合题

#### 考查要点
1. **定义**（书上定义）
2. **写完整的算法伪代码**
3. **用递归树或者主定理求复杂度**

#### 重点例题
- 快速排序（最好情况，最坏情况，均衡情况）
- 归并排序
- 求第k小元素

#### 解题规则
1. **分治法三步骤**：
   - 分解（Divide）：将原问题分解为若干规模较小的子问题
   - 解决（Conquer）：递归地解各个子问题
   - 合并（Merge）：将各个子问题的解合并为原问题的解

2. **伪代码书写规范**：
   ```
   算法名称(参数)
   输入：问题描述
   输出：问题解
   1. if 基本情况 then
   2.     直接求解
   3.     return 结果
   4. end if
   5. 分解问题
   6. for 每个子问题 do
   7.     递归调用
   8. end for
   9. 合并子问题的解
   10. return 最终结果
   ```

3. **复杂度分析方法**：
   - **主定理**：对于T(n) = aT(n/b) + f(n)
     - 情况1：若f(n) = O(n^(log_b(a) - ε))，则T(n) = Θ(n^(log_b(a)))
     - 情况2：若f(n) = Θ(n^(log_b(a)))，则T(n) = Θ(n^(log_b(a)) * logn)
     - 情况3：若f(n) = Ω(n^(log_b(a) + ε))，则T(n) = Θ(f(n))
   - **递归树方法**：画出递归树，计算每层工作量，求总和

4. **快速排序分析**：
   - 最好情况：每次划分均衡，T(n) = 2T(n/2) + n = O(nlogn)
   - 最坏情况：每次划分极端不平衡，T(n) = T(n-1) + n = O(n²)
   - 平均情况：O(nlogn)

5. **归并排序分析**：
   - T(n) = 2T(n/2) + n = O(nlogn)
   - 稳定排序

### 2.2 动态规划综合题

#### 考查要点
1. **动规概念、定义**（动态规划的三个性质）
2. **写动态转移方程**（写全）
3. **根据动态方程填表**

#### 重点例题
- 投资问题
- 0-1背包问题（大概率）
- 最长公共子序列
- 最大子段和

#### 解题规则
1. **动态规划三性质**：
   - 最优子结构性质
   - 重叠子问题性质
   - 无后效性

2. **解题步骤**：
   1. 找出最优解的性质，并刻画其结构特征
   2. 递归地定义最优值（写出状态转移方程）
   3. 以自底向上的方式计算出最优值（填表）
   4. 根据计算最优值时得到的信息构造最优解

3. **状态转移方程书写规范**：
   - 明确定义状态：dp[i][j]表示什么
   - 写出递推公式
   - 确定初始条件
   - 确定计算顺序

4. **0-1背包问题**：
   - 状态定义：dp[i][j]表示前i个物品在容量为j时的最大价值
   - 状态转移方程：
     ```
     dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])  if j >= w[i]
     dp[i][j] = dp[i-1][j]  if j < w[i]
     ```
   - 初始条件：dp[0][j] = 0, dp[i][0] = 0
   - 填表顺序：按物品编号递增，按容量递增

5. **最长公共子序列（LCS）**：
   - 状态定义：dp[i][j]表示X[1..i]和Y[1..j]的LCS长度
   - 状态转移方程：
     ```
     dp[i][j] = dp[i-1][j-1] + 1  if X[i] = Y[j]
     dp[i][j] = max(dp[i-1][j], dp[i][j-1])  if X[i] != Y[j]
     ```
   - 初始条件：dp[0][j] = 0, dp[i][0] = 0

6. **填表规范**：
   - 画出表格
   - 标注行列表示的含义
   - 按顺序填写每个格子
   - 标注计算顺序

### 2.3 贪心算法综合题

#### 考查要点
1. **贪心定义**（以书上的定义为准）
2. **三个算法**：Dijkstra、Prim、Kruskal中一个正确性证明
3. **三个算法的输出**：最短路径和最小生成树（画图）

#### 重点例题
- 算法证明

#### 解题规则
1. **贪心算法定义**：
   - 贪心算法在每一步选择中都采取在当前状态下最好或最优的选择
   - 贪心选择性质：所求问题的整体最优解可以通过一系列局部最优的选择来达到
   - 最优子结构性质：问题的最优解包含了其子问题的最优解

2. **贪心算法正确性证明方法**：
   - **交换论证**：假设存在一个最优解不包含贪心选择，通过交换得到一个更优或相等的解
   - **归纳法**：证明每一步贪心选择都能导致最优解

3. **Dijkstra算法**：
   - 用于单源最短路径问题
   - 贪心策略：每次选择距离源点最近的未访问顶点
   - 正确性证明：基于三角不等式
   - 时间复杂度：O(V²) 或 O((V+E)logV)

4. **Prim算法**：
   - 用于最小生成树问题
   - 贪心策略：每次选择连接已选顶点和未选顶点的最小权边
   - 正确性证明：基于切割性质
   - 时间复杂度：O(V²) 或 O(ElogV)

5. **Kruskal算法**：
   - 用于最小生成树问题
   - 贪心策略：每次选择权值最小的边，且不形成环
   - 正确性证明：基于安全边性质
   - 时间复杂度：O(ElogE)

6. **画图规范**：
   - 标注顶点和边
   - 标注边的权值
   - 用不同颜色或粗细标注选中的边
   - 标注选择顺序

### 2.4 回溯法综合题

#### 考查要点（最容易）
1. **搜索空间**（画搜索树）
2. **选策略**：DFS、BFS
3. **写剪枝条件**（约束条件）
4. **根据搜索空间列所有可行解**

#### 解题规则
1. **回溯法基本思想**：
   - 从根结点出发，按照深度优先策略搜索解空间树
   - 使用剪枝函数避免无效搜索

2. **解空间树类型**：
   - **子集树**：从n个元素的集合中找出满足某种性质的子集，复杂性O(2^n)
   - **排列树**：确定n个元素满足某种性质的排列，复杂性O(n!)

3. **解题步骤**：
   1. 定义问题的解空间
   2. 确定易于搜索的解空间结构
   3. 以深度优先方式搜索解空间
   4. 使用剪枝函数避免无效搜索

4. **剪枝函数**：
   - **约束函数**：在扩展结点处减去不满足约束的子树
   - **限界函数**：在扩展结点处减去得不到最优解的子树

5. **搜索树画法规范**：
   - 标注根结点
   - 标注每层的选择
   - 标注剪枝的位置
   - 标注可行解

6. **可行解列举规范**：
   - 按搜索顺序列出
   - 标注每个可行解的路径
   - 确保不遗漏

## 四、注意事项

### 4.1 答题规范
1. **必须按照题目要求写**：老师说必须要按照它那个写
2. **不能遗漏知识点**：确保全面完全的覆盖
3. **书写工整**：伪代码要清晰易读

### 4.2 重点复习内容
1. **分治法**：快速排序、归并排序、求第k小元素
2. **动态规划**：0-1背包问题（大概率）、最长公共子序列、最大子段和
3. **贪心算法**：Dijkstra、Prim、Kruskal的正确性证明和输出
4. **回溯法**：搜索空间、剪枝条件、可行解列举

### 4.3 常见错误
1. **伪代码不完整**：缺少输入输出说明
2. **状态转移方程不全**：缺少初始条件或边界情况
3. **复杂度分析错误**：主定理使用不当
4. **搜索树不完整**：遗漏剪枝或可行解
