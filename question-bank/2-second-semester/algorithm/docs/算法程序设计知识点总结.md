# 算法程序设计知识点总结

## 第一章：算法基础

### 1.1 算法的基本概念
- **算法的定义**：算法是把人类找到的求解问题的方法，用算法要素过程化、形式化、机械化地表示出来
- **算法的五大特征**：
  - 有穷性：一个算法的执行必须结束，计算步骤和每个步骤都能在有限时间内完成
  - 确定性：对于每种情况下所应执行的操作，在算法中都有确切的规定
  - 可行性：算法中描述的操作都可以通过已经实现的基本操作运算有限次实现
  - 输入性：有零个或多个输入
  - 输出性：有一个或多个输出

### 1.2 算法的要素
- **算法由以下要素组成**：
  - 操作
  - 控制结构
  - 数据结构
- **基本控制结构**：
  - 顺序结构
  - 选择结构
  - 循环结构

### 1.3 算法的描述形式
- 自然语言
- 程序设计语言
- 伪代码
- 流程图

### 1.4 算法与数据结构的关系
- 数据结构是算法设计的基础
- 算法是编程思想，数据结构则是这些思想的逻辑基础
- 算法设计就是在选定的存储结构上设计一个满足要求的好算法

### 1.5 算法的设计目标
- **正确性**：一切合法的输入数据都能得出满足要求的结果，包括典型的、苛刻的输入数据
- **可使用性**（用户友好性）
- **健壮性**：算法要对异常情况进行适当的处理
- **效率**：时间复杂度和空间复杂度

### 1.6 算法分析
- **时间复杂度**：算法执行时间与问题规模n之间的增长关系
- **空间复杂度**：算法占用存储空间与问题规模n之间的增长关系
- **渐近符号**：
  - O符号：上界
  - Ω符号：下界
  - Θ符号：紧确界（既是上界又是下界）

## 第二章：递归与分治

### 2.1 递归
- **递归的定义**：直接或间接地调用自身的算法称为递归算法
- **递归函数**：用函数自身给出定义的函数
- **递归的要素**：
  - 递归出口（基本情况）
  - 递归调用（递归情况）

### 2.2 分治法
- **分治法的基本思想**：将一个复杂的问题分成两个或更多的相同或相似的子问题，直到最后子问题可以简单的直接求解，原问题的解即子问题的解的合并
- **分治法的适用条件**：
  - 问题的规模缩小到一定的程度就可以容易地解决
  - 问题可以分解为若干个规模较小的问题
  - 利用该问题分解出的子问题的解可以合并为该问题的解
  - 该问题具有最优子结构性质

### 2.3 分治法的基本步骤
1. 分解（Divide）：将原问题分解为若干规模较小、相互独立、与原问题形式相同的子问题
2. 解决（Conquer）：若子问题规模较小而容易被解决则直接解，否则递归地解各个子问题
3. 合并（Merge）：将各个子问题的解合并为原问题的解

### 2.4 典型分治算法
- **归并排序**：时间复杂度O(nlogn)
- **快速排序**：平均时间复杂度O(nlogn)，最坏O(n²)
- **二分查找**：时间复杂度O(logn)
- **大整数乘法**
- **Strassen矩阵乘法**
- **棋盘覆盖**
- **最近点对问题**

### 2.5 递推方程求解
- **主定理（Master Theorem）**：
  - 对于T(n) = aT(n/b) + f(n)：
    - 若f(n) = O(n^(log_b(a) - ε))，则T(n) = Θ(n^(log_b(a)))
    - 若f(n) = Θ(n^(log_b(a)))，则T(n) = Θ(n^(log_b(a)) * logn)
    - 若f(n) = Ω(n^(log_b(a) + ε))，则T(n) = Θ(f(n))
- **递归树方法**
- **迭代方法**

## 第三章：动态规划

### 3.1 动态规划的基本概念
- **定义**：动态规划算法与分治法类似，其基本思想也是将待求解问题分解成若干个子问题
- **主要差别**：子问题是否相互独立（动态规划的子问题不是相互独立的）

### 3.2 动态规划的三个性质
1. **最优子结构性质**：当问题的最优解包含了其子问题的最优解时，称该问题具有最优子结构性质
2. **重叠子问题性质**：在用递归算法自顶向下解此问题时，每次产生的子问题并不总是新问题，有些子问题被反复计算
3. **无后效性**：某阶段的状态一旦确定，则此后过程的演变不再受此前各种状态的影响

### 3.3 动态规划的基本步骤
1. 找出最优解的性质，并刻画其结构特征
2. 递归地定义最优值
3. 以自底向上的方式计算出最优值
4. 根据计算最优值时得到的信息构造最优解

### 3.4 动态规划与分治法的区别
- **分治法**：子问题相互独立，自顶向下求解
- **动态规划**：子问题不相互独立，有重叠，自底向上求解

### 3.5 典型动态规划问题
- **投资问题**
- **0-1背包问题**（重点）
- **最长公共子序列（LCS）**
- **最大子段和**
- **矩阵连乘问题**
- **最优二叉搜索树**
- **流水作业调度问题**

### 3.6 动态规划的时间复杂度
- 通常不同的子问题个数随问题的大小呈多项式级增长
- 用动态规划法只需要非指数或非阶乘的时间，从而获得较高的解题效率

## 第四章：贪心算法

### 4.1 贪心算法的基本概念
- **定义**：贪心算法在每一步选择中都采取在当前状态下最好或最优（即最有利）的选择，从而希望导致结果是最好或最优的算法
- **特点**：贪心算法则通常以自顶向下的方式进行，以迭代的方式作出相继的贪心选择

### 4.2 贪心算法的性质
1. **贪心选择性质**：所求问题的整体最优解可以通过一系列局部最优的选择来达到
2. **最优子结构性质**：当问题的最优解包含了其子问题的最优解时，称该问题具有最优子结构性质

### 4.3 贪心算法与动态规划的区别
- 贪心算法做出的选择既不依赖于目前的选择，也不依赖于任何未来的选择或子问题的解
- 动态规划需要考虑子问题的解

### 4.4 贪心算法的适用条件
- 问题具有贪心选择性质
- 问题具有最优子结构性质
- 问题具有递归性质

### 4.5 典型贪心算法
- **活动安排问题**：选择结束时间最早的活动
- **最优装载问题**：选择重量最轻的集装箱
- **哈夫曼编码**：构造最优前缀码
- **单源最短路径（Dijkstra算法）**
- **最小生成树（Prim算法、Kruskal算法）**
- **多机调度问题**：最长处理时间作业优先
- **汽车加油问题**：最远加油站优先
- **最小延迟时间问题**：优先选择截止时间最早的任务

### 4.6 贪心算法的正确性证明
- 要证明一个问题不能用贪心策略去解，一个简单方法就是对假设的贪心选择性质找出一个反例
- 证明方法：交换论证、归纳法

## 第五章：回溯法

### 5.1 回溯法的基本概念
- **定义**：回溯法是一种系统地搜索问题解的方法
- **基本思想**：从根结点出发，按照深度优先策略搜索解空间树

### 5.2 解空间树
- **子集树**：当所给的问题是从n个元素的集合S中找出满足某种性质的子集时，相应的解空间树称为子集树，复杂性通常是O(2^n)
- **排列树**：当所给的问题是确定n个元素满足某种性质的排列时，相应的解空间树称为排列树，复杂性通常是O(n!)

### 5.3 回溯法的基本步骤
1. 定义问题的解空间
2. 确定易于搜索的解空间结构
3. 以深度优先方式搜索解空间，并在搜索过程中用剪枝函数避免无效搜索

### 5.4 剪枝函数
- **约束函数**：在扩展结点处减去不满足约束的子树
- **限界函数**：在扩展结点处减去得不到最优解的子树

### 5.5 回溯法的搜索策略
- **深度优先搜索（DFS）**
- **广度优先搜索（BFS）**

### 5.6 典型回溯问题
- **N皇后问题**
- **图的m着色问题**
- **旅行商问题**
- **装载问题**
- **批处理作业调度问题**

---

## 第六章：分支限界法

### 6.1 分支限界法的基本概念
- **定义**：分支限界法是一种在问题的解空间树上搜索问题解的算法
- **基本思想**：以广度优先或最小耗费（最大效益）优先的方式搜索解空间树

### 6.2 分支限界法与回溯法的区别
- **回溯法**：深度优先搜索，找出满足约束条件的所有解
- **分支限界法**：广度优先或优先队列搜索，找出满足约束条件的一个解或特定意义下的最优解

### 6.3 分支限界法的类型
1. **队列式(FIFO)分支限界法**：按照队列先进先出（FIFO）原则选取下一个结点为扩展结点
2. **优先队列式分支限界法**：按照优先队列中规定的优先级选取优先级最高的结点成为当前扩展结点

### 6.4 限界函数
- **上界限界函数**：用于求解最大化问题
- **下界限界函数**：用于求解最小化问题
- **设计原则**：一般表示其接近最优解的程度

### 6.5 分支限界法的基本步骤
1. 定义问题的解空间
2. 确定解空间树的结构
3. 以广度优先或最小耗费（最大效益）优先的方式搜索解空间树

### 6.6 典型分支限界问题
- **0/1背包问题**
- **旅行商问题**
- **单源最短路径问题**
- **任务分配问题**
- **流水作业调度问题**

### 6.7 分支限界法的复杂度
- 最坏时间复杂度：O(2^n)
- 最坏空间复杂度：O(2^n)

## 第七章：算法设计策略总结

### 7.1 算法设计策略比较

| 策略 | 基本思想 | 搜索方式 | 解的个数 | 典型应用 |
|------|----------|----------|----------|----------|
| 分治法 | 分解-解决-合并 | 递归 | 一个 | 归并排序、快速排序 |
| 动态规划 | 自底向上填表 | 自底向上 | 一个 | 背包问题、LCS |
| 贪心法 | 局部最优选择 | 自顶向下 | 一个 | 活动安排、哈夫曼 |
| 回溯法 | 深度优先搜索 | 深度优先 | 所有 | N皇后、图着色 |
| 分支限界 | 广度优先/优先队列 | 广度优先 | 一个/最优 | 0/1背包、TSP |

### 7.2 算法复杂度分析
- **时间复杂度**：
  - O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(n³) < O(2^n) < O(n!)
- **空间复杂度**：
  - 原地算法：O(1)
  - 递归算法：O(logn) 或 O(n)

### 7.3 算法选择指南
1. **问题规模小**：可以使用回溯法或分支限界法
2. **问题具有最优子结构**：考虑动态规划或贪心算法
3. **问题可以分解为独立子问题**：考虑分治法
4. **需要所有解**：使用回溯法
5. **需要最优解**：考虑动态规划、贪心算法或分支限界法

## 重点算法总结

### 必考算法
1. **快速排序**：最好、最坏、平均情况的时间复杂度
2. **归并排序**：时间复杂度O(nlogn)
3. **0-1背包问题**：动态规划解法
4. **最长公共子序列**：动态规划解法
5. **Dijkstra算法**：最短路径
6. **Prim算法**：最小生成树
7. **Kruskal算法**：最小生成树

### 重要概念
1. 算法的五大特征
2. 渐近符号（O、Ω、Θ）
3. 动态规划的三个性质
4. 贪心算法的两个性质
5. 回溯法与分支限界法的区别
