## 第一部分：知识点
### 一、网络体系结构

#### 2. 分层关系原则
- **下层为上层提供服务**（第 k 层为第 k+1 层服务）
- **屏蔽细节**：上层不需要知道下层如何实现
- **透明性**：下层服务对上层透明
#### 3. 网络协议三要素
- **语法**：数据与控制信息的结构或格式
- **语义**：需要发出何种控制信息，完成何种动作及做出何种响应
- **同步/时序**：事件实现顺序的详细说明
#### 4. 物理层接口四大特性
| 特性         | 描述内容                     | 举例                      |
| ---------- | ------------------------ | ----------------------- |
| 机械特性       | 接口连接器的形状、尺寸、引脚数量和排列      | 9针D型接口、RJ-45引脚布局        |
| 电气特性       | 电压范围、电平代表的逻辑（0或1）、传输速率限制 | RS-232中 +3V～+15V 代表逻辑 0 |
| 功能特性       | 各个引脚/信号线的具体用途            | TXD（发送数据）、RXD（接收数据）引脚定义 |
| 过程特性（规程特性） | 完成各种功能时，各信号线动作的先后顺序和时序关系 | 握手的先后步骤                 |
### 二、物理层
#### 1. 数据通信基础
- **常用交换技术**：电路交换、报文交换、分组交换
- **信道复用方式**：频分复用（FDM）、波分复用（WDM）、码分复用（CDM）、时分复用（TDM）
- **数据传输方式**：串行传输、并行传输
- **传输媒体分类**：导向传输媒体、非导向传输媒体
#### 2. 调制技术
- **基本带通调制方法**：调幅（AM）、调相（PM）、调频（FM）
- **数→模 是调制（Modulation）**
- **模→数 是解调（Demodulation）**
- **PCM（脉冲编码调制）过程**：采样 → 量化 → 编码
#### 3. 编码方式
- **归零码**：不含同步时钟信息
- **曼彻斯特编码**：含同步时钟信息（每个码元中间有跳变）
- **差分曼彻斯特编码**：含同步时钟信息
#### 4. 光纤接入网分类
| 缩写 | 全称 | 含义 |
|------|------|------|
| FTTH | Fiber To The Home | 光纤到户 |
| FTTB | Fiber To The Building | 光纤到大楼 |
| FTTC | Fiber To The Curb | 光纤到路边 |
#### 5. RS-232C
- 串行物理接口标准，属于**物理层**
- 规定了 DTE 和 DCE 之间接口的机械、电气、功能和规程特性
### 三、数据链路层
#### 1. 信道类型
- **广播信道**：一对多通信
- **点对点信道**：一对一通信
#### 2. 数据链路层服务
| 服务类型 | 适用场景 |
|----------|----------|
| 无确认无连接 | 误码率低、实时性要求高的传输环境 |
| 有确认无连接 | 无线通信等不可靠信道 |
| 有确认有连接 | 可靠性要求高的传输 |
#### 3. 帧同步方法
| 方法    | 协议            | 原理                 |
| ----- | ------------- | ------------------ |
| 违法编码法 | IEEE 802（以太网） | 利用曼彻斯特编码的违规跳变标识帧起始 |
| 字符填充法 | PPP 协议        | 使用转义字符区分帧边界        |
| 比特填充法 | HDLC 协议       | 连续5个1后插入0          |
| 字节计数法 | -             | 首部指明帧长度            |
#### 4. 差错检测
| 层次    | 检错方式        | 检错范围      |
| ----- | ----------- | --------- |
| 物理层   | 奇偶校验、编码检错   | 比特级       |
| 数据链路层 | CRC（循环冗余校验） | 整个帧       |
| 网络层   | 首部校验和       | 只校验首部     |
| 传输层   | TCP/UDP 校验和 | 整个报文段/数据报 |
#### 5. 交换机转发方式
- **存储转发**：接收完整帧后转发，检错能力强
- **无碎片转发**：接收64字节后转发
- **直通转发**：读取目的MAC后立即转发，延迟最低
### 四、介质访问控制（MAC）
#### 1. MAC 协议分类
| 类型 | 代表技术 | 特点 |
|------|----------|------|
| 随机接入（争用型） | ALOHA、CSMA、CSMA/CD、CSMA/CA | 冲突可能发生 |
| 受控接入（轮询型） | 令牌传递（Token Passing）、轮询 | 严格避免冲突 |
#### 2. CSMA/CD vs CSMA/CA
| 特性 | CSMA/CD | CSMA/CA |
|------|---------|---------|
| 应用场景 | 有线以太网 | 无线局域网（Wi-Fi） |
| 工作方式 | 边发边听，检测冲突 | 先听后说，避免冲突 |
| 冲突处理 | 检测到冲突立即停止 | RTS/CTS 握手预约信道 |
| 原因 | 支持全双工，可同时收发 | 无线无法同时收发（自干扰） |
#### 3. CSMA/CD 关键参数
- **冲突检测时间**：信号在最远两端的往返传输时间（2τ）
- **最小帧长保证**：帧的发送时间 ≥ 2τ
- **总线长度增加** → 传播时延变大 → 冲突窗口变大 → 加剧冲突
#### 4. CSMA vs TDMA 适用场景
| 特性 | CSMA/CD | TDMA |
|------|---------|------|
| 负载轻时 | ✅ 效率高 | ❌ 信道有浪费 |
| 负载重时 | ❌ 冲突严重 | ✅ 稳定高效 |
| 适用场景 | 突发性、间歇性流量 | 连续、大数据量、重负载 |
#### 5. 802.3 以太网
- 采用 **CSMA/CD** 媒体访问控制技术
### 五、网络层
#### 1. 路由器主要功能
- **路由选择**：确定最佳路径
- **分组转发**：将数据包从输入端口转移到输出端口
#### 2. 子网掩码
- **"1"代表网络位**：标识主机属于哪个网段
- **"0"代表主机位**：标识网段内的具体设备
- **核心原则**：1必须连续在左，0必须连续在右
- **与运算**：IP地址 AND 子网掩码 = 网络号
- **口诀**："1"划网，"0"定机
#### 3. ARP 协议
- **功能**：将 IP 地址解析为 MAC 地址
- **所属层次**：网络层（网际层）
- **工作范围**：同一局域网内（不经过路由器）
- **封装方式**：封装在以太网帧的数据部分
#### 4. ICMP 协议
- **报文类型**：差错报告报文、查询报文
- **封装方式**：封装在 IP 数据报的数据部分
- **协议号**：1
- **特点**：不同差错报告报文对应不同的代码值
#### 5. RIP 协议（距离向量）
- **算法**：距离向量（Distance Vector）算法
- **度量标准**：跳数（Hop Count）
- **最大有效跳数**：15 跳
- **不可达标识**：16 跳
- **收敛速度**：慢
- **RIPv1**：不支持子网掩码（有类别）
- **RIPv2**：支持子网掩码
#### 6. OSPF 协议（链路状态）
- **算法**：链路状态（Link State）算法，使用 Dijkstra
- **度量标准**：带宽、延迟等（不单纯依赖跳数）
- **特点**：收敛速度快，支持大型网络
- **类别**：无类别路由协议（支持 VLSM 和 CIDR）
#### 7. IPv4 数据报首部

| 字段 | 位数 | 说明 |
|------|------|------|
| 版本 (Version) | 4位 | IPv4 固定为 4 |
| 首部长度 (HLEN) | 4位 | **单位是 4 字节**，最小5（20字节），最大15（60字节） |
| 服务类型 (ToS) | 8位 | 服务质量参数 |
| 总长度 | 16位 | 首部+数据的总字节数，最大65535字节 |
| 标识 | 16位 | 分片重组的"身份证号"，同一数据报的所有分片标识相同 |
| 标志 | 3位 | DF=1不可分片，MF=1后面还有分片 |
| 片偏移 | 13位 | **单位是 8 字节**，表示分片在原数据报中的相对位置 |
| 生存时间 TTL | 8位 | 每经过一个路由器减1，减到0丢弃并发送ICMP超时报文 |
| 协议 | 8位 | 6=TCP，17=UDP，1=ICMP |
| 首部校验和 | 16位 | 只校验首部，每经过路由器需重新计算 |
| 源IP地址 | 32位 | 发送方IP |
| 目的IP地址 | 32位 | 接收方IP |
**记忆口诀**：版头总标标偏，TTL 协校源地
### 六、传输层
#### 1. TCP 协议
- **面向连接**：三次握手建立连接，四次挥手释放连接
- **可靠传输**：确认重传机制
- **协议号**：6
#### 2. UDP 协议
- **无连接**：不建立连接直接发送
- **不可靠**：不保证数据到达
- **协议号**：17
#### 3. 停-等协议
- 发送一帧后等待确认，再发送下一帧
- 信道利用率 = 发送时延 / (发送时延 + 2×传播时延)
#### 4. 后退N帧 ARQ 协议
- 发送窗口最大长度 = 2^n - 1（n 为帧编号字段位数）
- 例：帧编号字段7位 → 发送窗口最大长度 = 2^7 - 1 = 127
### 七、应用层
#### 1. FTP 协议（文件传输协议）
- **两个连接**：
  - 控制连接：端口 21，传输命令和响应，整个会话保持
  - 数据连接：端口 20，传输文件数据，传输完关闭
- **建立顺序**：先建立控制连接，需要传输数据时再建立数据连接
#### 2. TFTP 协议
- **全称**：Trivial File Transfer Protocol（简单文件传输协议）
- **基于 UDP**，设计简单，用于局域网内文件传输
#### 3. HTTP 协议
- **万维网（WWW）组成**：资源、统一资源定位符（URL）、传输协议（HTTP）
#### 4. DNS 协议
- **功能**：域名解析
#### 5. SMTP/POP3
- **功能**：电子邮件协议
### 八、网络拓扑与分类
#### 1. 按拓扑结构分类
- 总线形、星形、树形、环形、网状形、混合
#### 2. 逻辑子网划分
- **通信子网**：负责数据传输
- **资源子网**：提供资源共享
#### 3. 最大传输单元
- **MTU**（Maximum Transmission Unit）：以太网通常为 1500 字节
### 九、TDM 时分复用

## 第二部分：计算题目
### 题型一：香农公式（有噪声信道极限速率）
**公式**：C = B × log₂(1 + S/N)
其中：C 为信道容量（bps），B 为带宽（Hz），S/N 为信噪比（数值比）
**注意**：
- 若信噪比给出 dB 值，需先转换：S/N(dB) = 10×log₁₀(S/N) → S/N = 10^(dB/10)
- 奈奎斯特公式（无噪声）：C = 2B × log₂(V)，V 为信号码元状态数
**【原题1】** 如果某信道的带宽为4KHz，信噪比为30dB，则该信道的极限信息传输速率为( )。
**解析**：
- 先将 dB 转换为数值比：30 = 10×log₁₀(S/N) → S/N = 10^3 = 1000
- C = 4000 × log₂(1 + 1000) = 4000 × log₂(1001) ≈ 4000 × 9.97 ≈ 39880 bps ≈ 40 Kbps
**答案**：40 Kbps
**【练习1】** 如果某信道的带宽为8kHz，信噪比为30dB，则该信道的极限信道传输速率为（ ）。
A. 10kbps  B. 40kbps  C. 80kbps
**解析**：
- S/N = 10^(30/10) = 1000
- C = 8000 × log₂(1001) ≈ 8000 × 9.97 ≈ 79760 bps ≈ 80 kbps
**答案**：C
**【练习2】** 某信道带宽3kHz，信噪比为1023，则信道的最大数据传输速率是( )bps？
**解析**：
- 信噪比直接给出数值比，无需转换
- C = 3000 × log₂(1 + 1023) = 3000 × log₂(1024) = 3000 × 10 = 30000 bps
**答案**：30000 bps
### 题型二：奈奎斯特公式（无噪声信道极限速率）
**公式**：C = 2B × log₂(V)
其中：V 为信号码元可取的离散值个数（振幅等级数）
**【原题2】** 假定某信道受奈氏准则限制的最高码元速率为 20000 码元/秒。如果采用振幅调制，把码元的振幅划分为16个不同等级来传送，那么可以获得多高的数据率？
**解析**：
- C = 20000 × log₂(16) = 20000 × 4 = 80000 bps
**答案**：80000 bps
**【练习1】** 某信道带宽4kHz，如果采用振幅调制，把振幅划分为16个不同等级来传送，则最大传输率( )。
**解析**：
- 最高码元速率 = 2B = 2 × 4000 = 8000 码元/秒
- C = 8000 × log₂(16) = 8000 × 4 = 32000 bps = 32 kbps
**答案**：32 kbps
**【练习2】** 为了在1 MHz带宽的信道上得到 4 Mbps 的比特率，信噪比需要达到多少？
**解析**：
- C = B × log₂(1 + S/N)
- 4 × 10^6 = 1 × 10^6 × log₂(1 + S/N)
- log₂(1 + S/N) = 4
- 1 + S/N = 2^4 = 16
- S/N = 15
**答案**：15
### 题型三：调制速率（波特率）与数据传输速率
**关系**：C = B × log₂(K)
其中：C 为数据传输速率（bps），B 为调制速率/波特率（Baud），K 为信号可取的离散值个数
**【原题3】** 已知数据传输速率C=14400bps，多相调制的相数（信号可能的取值个数）K=8，则调制速率（波特率）是（ ）。
**解析**：
- B = C / log₂(K) = 14400 / log₂(8) = 14400 / 3 = 4800 Baud
**答案**：4800 Baud
**【练习1】** 某信道的信号传输速率为2000baud，若想令其数据传输速率达到8Kbps，则一个信号码元所取的有效离散值个数应为( )。
**解析**：
- C = B × log₂(K)
- 8000 = 2000 × log₂(K)
- log₂(K) = 4
- K = 2^4 = 16
**答案**：16
**【练习2】** 若采用8相调制（K=8），波特率为2400 Baud，则数据传输速率是多少？
**解析**：
- C = B × log₂(K) = 2400 × log₂(8) = 2400 × 3 = 7200 bps
**答案**：7200 bps
### 题型四：CSMA/CD 冲突检测时间
**核心公式**：
- 单程传播时延 τ = 距离 / 传播速率
- 冲突检测最长时间 = 2τ（往返时间）
- 冲突检测最短时间 = τ（单程时间）
**【原题4】** 假定在使用CSMA/CD协议的10Mb/s以太网，主机A与B相距2km，设信号在网络上的传播速率为200000km/s。若主机A与主机B发送的数据发生冲突，则从开始发送数据时刻起到双方均检测到冲突为止，经过的最长时间是（ ）。
**解析**：
- 单程传播时延 τ = 2km / 200000km/s = 0.00001s = 10μs
- 最长时间 = 2τ = 2 × 10μs = 20μs
**答案**：20μs
**【练习1】** 假定在使用CSMA/CD协议的10Mb/s以太网，主机A与B相距2km，设信号在网络上的传播速率为200000km/s。若主机A与主机B发送的数据发生冲突，则从开始发送数据时刻起到双方均检测到冲突为止，经过的最短时间是（ ）。
**解析**：
- 单程传播时延 τ = 2km / 200000km/s = 10μs
- 最短时间 = τ = 10μs
**答案**：10μs
**【练习2】** 网络距离为1KM，带宽为10M，采用CSMA/CD方式，信号传播速度为2C/3（C为光速，即2×10^8 m/s），则最小帧长度为（ ）。
**解析**：
- 传播速度 = 2/3 × 3×10^8 = 2×10^8 m/s
- 单程传播时延 τ = 1000m / (2×10^8 m/s) = 5×10^-6 s = 5μs
- 冲突检测时间 = 2τ = 10μs
- 最小帧长 = 带宽 × 冲突检测时间 = 10×10^6 × 10×10^-6 = 100 bit
**答案**：100 bit
### 题型五：发送时延与传播时延
**公式**：
- 发送时延 = 数据量(bit) / 发送速率(bps)
- 传播时延 = 距离(m) / 传播速率(m/s)
- 总时延 = 发送时延 + 传播时延
**【原题5】** 设网络带宽为1 Gbps，传输的消息为2.5kbyte，发送者和接收者之间的距离为12000 km，光以2.4×10^8 m/s的速度传播，则传输时延与传播时延各是多少？
**解析**：
- 发送时延 = (2.5 × 1024 × 8) / (1 × 10^9) = 20480 / 10^9 ≈ 0.00002048s ≈ 0.02ms
- 传播时延 = 12000×10^3 / (2.4×10^8) = 0.05s = 50ms
**答案**：发送时延 0.02ms，传播时延 50ms

### 题型九：信道利用率
**公式**：
- 信道利用率 = 发送时延 / (发送时延 + 往返传播时延)
- 停-等协议：U = (L/R) / (L/R + 2×RTT)
**【原题9】** 假设信道长度为1200km，其端到端传播往返时间为20ms，分组长度为1200bit，发送速率为1Mb/s。若忽略处理时间和发送确认分组时间，则该信道的利用率是多少？
**解析**：
- 发送时延 = 1200bit / 1Mbps = 1200 / 10^6 = 0.0012s = 1.2ms
- 往返传播时延 = 20ms
- 利用率 = 1.2 / (1.2 + 20) = 1.2 / 21.2 ≈ 5.7%
**答案**：5.7%
**【练习1】** 信道速率4kbps，采用停-等协议。单程传播时延10ms，若忽略处理时间和发送确认分组时间，则帧长为多少比特时信道利用率达到50%？
**解析**：
- 设帧长为 L bit
- 发送时延 = L / 4000 s
- 往返传播时延 = 2 × 10ms = 20ms = 0.02s
- 利用率 = (L/4000) / (L/4000 + 0.02) = 0.5
- L/4000 = 0.5 × (L/4000 + 0.02)
- L/4000 = 0.5L/4000 + 0.01
- 0.5L/4000 = 0.01
- L = 0.01 × 4000 / 0.5 = 80 bit
**答案**：80 bit
**【练习2】** 32个用户共享2.048 Mbps链路，使用TDM。每个用户当轮使用时，以全速度发送8位。用户需要多长时间才能发送一次？
**解析**：
- 总速率 = 2.048 Mbps = 2048 kbps
- 每个用户的速率 = 2048 / 32 = 64 kbps
- 发送8位的时间 = 8 / 64000 = 0.000125s = 125μs
- TDM帧周期 = 125μs
**答案**：125μs

### 题型十二：CSMA/CD 最小帧长与网络距离
**公式**：

- 距离变化量 = 帧长变化量 / (2 × 带宽 / 传播速率)

- = 800 / (2 × 5)
- = 800 / 10
- = 80m
